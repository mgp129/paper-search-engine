# 约 3 分钟的演示操作与讲解稿

使用组员提供的“论文检索系统”页面。不要打开已隔离的旧版“文献检索台”。

## 录屏前

双击根目录 `启动项目.bat`，打开 <http://127.0.0.1:8501>。建议浏览器缩放 100%，窗口 1600×900 或 1920×1080。保持搜索框为空、分类不选、AND 不勾选、每页 10 条。

完整无声操作示例见 `demo/组员版_演示.webm`。正式录屏可按下表操作并配音。

## 简短答辩口径

- **为何不单独部署后端？** 本项目规模为 800 篇，Streamlit 直接调用本地 `search_api.py` 和检索内核，部署步骤少，能满足课程演示需求。
- **检索算法是什么？** 英文分词与停用词过滤、倒排索引、BM25，加上标题权重和短语加成。
- **得分是准确率吗？** 不是。得分用于同一查询的排序。正式语料尚未完整标注相关性，因此不报告正式召回率或准确率。
- **能用中文查吗？** 当前标题摘要为英文，没有中文翻译或语义跨语言检索，演示使用英文关键词。
- **为什么年份不能拖动？** 当前正式数据都属于 2026 年，页面按实际数据静态展示首次提交年份。
- **联网是否必要？** 本地搜索和摘要浏览不需要。首次安装依赖和打开 arXiv 原文需要网络。

当前数据只包含元数据与摘要，不包含 PDF 正文。不要把未来的向量检索、中文查询映射或大模型总结说成已经完成的功能。不制作 PPT。
