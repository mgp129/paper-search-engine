# 组员版检查与最终修改说明

## 版本来源

最终运行版以用户提供的 `abc汇总.zip` 为基线。压缩包的原始项目解包保存在 `_incoming/teammate_original/`。其中 `.box-agent` 等打包元数据没有作为项目代码或指令执行。

先前 Codex 自建界面及对应样式、测试、视频等保存在 `_archive/codex_demo_previous_20261105/`，旧服务已停止，不参与最终运行和打包。当前页面沿用组员 `app.py` 的搜索卡片和独立详情页结构。

## 功能完整性检查

组员版已具备 A 数据、B 检索、C 页面和适配层。搜索、OR/AND、分类与年份条件、排序、摘要高亮、分页、详情和空查询浏览均有实现。原始 12 项 API/页面测试本次已重新运行并通过。

B 的历史说明提到的独立索引构建、召回评测脚本和 9 项 B 测试未包含在压缩包中。它们不是当前页面运行依赖，不阻塞演示；文档已改为使用实际存在的验收命令。历史 18 篇样例评测不当作正式语料效果。

## 最小代码修改

1. `app.py` 显式保留搜索控件状态，详情进入/返回改用回调。补充测试验证关键词、分类、AND、排序、每页条数、页码和结果 ID 均保留。
2. `app.py` 在空查询浏览时显示“浏览模式”，不展示没有查询依据的 0 分；年份标签改为“首次提交年份”；详情显示完整作者列表。
3. `search_api.py` 删除样例数据自动回退，只在两份正式数据中选择；路径基于模块绝对位置定位。
4. 将 Streamlit 固定为本次实测的 1.45.0，补充双击启动和 PowerShell 启动入口。
5. 配置固定浅色外观、本机监听和非开发者工具栏，未引入旧版页面的自定义样式。

A 的采集清洗脚本、正式数据及 B 的 `paper_search` 检索代码保持组员原样。最终逐文件比对见 `docs/版本文件校验.json`。

## 实际验证

- 本地数据校验：UTF-8、字段类型、ID、文本、统计守恒和文件哈希通过。
- 自动测试：组员原有 12 项、A 的 8 项、新增回归 3 项，共 23 项通过。
- 实际浏览器：800 篇浏览、OR 182 篇及高亮、AND 33 篇、翻页、完整摘要和原文入口、详情返回状态保持、分类浏览 200 篇、无结果提示、无页面异常，共 9 项通过。
- `demo/01_home.png` 至 `04_filter.png` 和 `demo/组员版_演示.webm` 来自上述最终页面，未复用旧版截图或视频。

演示材料不包含 PPT。没有逐篇重新访问全部 arXiv 外链，也未进行正式语料的人工相关性评测。
