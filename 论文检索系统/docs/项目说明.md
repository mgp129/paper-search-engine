# 科研论文检索系统项目说明

## 项目目标

本项目围绕科研与知识挖掘方向，实现论文元数据的采集、清洗、关键词检索和浏览。用户能够输入英文关键词，在论文标题与摘要中查找相关内容，结合分类和匹配方式缩小范围，查看摘要和原文入口。

当前交付目标是可以在本地稳定启动并完成完整演示。项目采用组员提供的 A、B、C 模块，不要求在线实时采集或额外部署独立数据库服务。

## 数据来源与处理

A 模块使用 arXiv 官方 API 获取论文元数据，覆盖 `cs.IR`、`cs.CL`、`cs.LG`、`cs.AI` 四个主分类，每类 200 篇，共 800 篇。开发版有 150 篇，正式运行优先读取 `paper-data/data/papers_final.jsonl`。

每条记录包含 `paper_id`、`title`、`abstract`、`authors`、`year`、`category`、`url`、`source`。清洗包括去除 ID 版本号后去重、解码 HTML 实体、合并空白、过滤缺失标题摘要及其他异常记录。标题与摘要保留原文，分词由检索模块完成。

当前论文全部为 2026 年，`year` 表示首次提交年份。项目只打包元数据和摘要，没有下载论文 PDF。

## 检索实现

B 模块使用 Python 标准库实现倒排索引和 BM25 评分。文本经过英文小写分词和停用词过滤后进入索引。标题 token 默认重复两次以增加权重，BM25 使用词频、逆文档频率和文档长度归一化；完整查询短语命中时增加少量加分。

默认 OR 语义允许命中任意有效查询词。AND 模式要求所有有效查询词都出现在论文中。检索还支持年份、单分类或多分类过滤，以及相关性、年份和标题排序，并通过 offset/Top-K 返回分页结果。

## 适配层与页面

C 的 `search_api.py` 调用 B 的公开接口，把 `paper_id` 转成页面的 `id`，把年份转换为展示字符串，把主分类转换为列表，并给命中片段添加高亮标记。适配层还补充空关键词全量浏览和按 ID 查询详情。索引在进程内缓存，页面不会在每次搜索时重复建立索引。

`app.py` 使用 Streamlit 展示搜索框、筛选栏、结果卡片、分页和独立详情页。页面处理无结果、非法参数和初始化失败。最终集成补充了详情往返的状态保持，避免返回后丢失检索上下文。

## 验收结果

本次本地校验确认 800 篇正式论文全部加载，跳过记录为 0，索引词表 11,672 项。23 项自动测试全部通过，真实浏览器另外完成 9 项检查。

正式数据中，`dense retrieval` 默认 OR 返回 182 篇，AND 返回 33 篇。空关键词浏览返回 800 篇，分类 `cs.IR` 返回 200 篇。翻页后进入详情并返回，原查询、AND 设置与页码保持不变。

这些数字用于说明功能和筛选行为。800 篇正式数据尚无完整人工相关性标注，不据此报告 Recall 或 Precision。根目录的历史评测报告来自 18 篇样例，只能作为样例测试材料。

## 分工与后续

A 负责采集清洗与数据说明，B 负责索引和评分，C 负责接口适配和页面，演示收尾负责启动说明、运行核验、操作脚本及实际录屏。后续可以补充历史年份、中文查询映射和人工相关性标注，这些不属于当前已实现范围。
